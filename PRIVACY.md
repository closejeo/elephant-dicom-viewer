# Privacy Policy — Elephant DICOM Viewer

Last updated: 2026-11-01

Elephant DICOM Viewer is a free desktop program for viewing medical images (DICOM, NIfTI and common picture formats) for education and research. It is not intended for diagnosis.

## Summary
**The program does not collect, store, send or share any personal data.** It works fully offline.

## Details
- **No network access.** The program does not connect to the internet or any server. It contains no analytics, advertising, tracking or crash reporting.
- **Your images stay on your computer.** Files are only opened from locations you choose. Exported images, DICOM / NIfTI files and videos are written only to the folder you choose.
- **Local settings only.** The program keeps a few small settings on your own computer (for example the interface language and whether the usage notice has been accepted), in `%LocalAppData%\ElephantDicomViewer`. They contain no image data and no patient information, and they never leave your computer.
- **Temporary files.** Files unpacked from zip archives are stored temporarily on your computer and removed when they are closed.
- **Several windows.** When several program windows are open, they share only the crosshair position with each other, inside your computer.
- **Patient information.** DICOM files may contain patient information. It is shown only on your screen. Optional functions can hide it while recording videos or remove it when exporting (anonymization). You are responsible for handling patient data according to the rules that apply to you.

## Microsoft Store
If you install the program from the Microsoft Store, Microsoft may collect information about the download and installation under its own privacy statement. The developers of Elephant DICOM Viewer do not receive any personal data from it.

# 隐私政策 —— Elephant DICOM Viewer（小象阅片器）

更新日期：2026-11-01

小象阅片器是一款免费的桌面程序，用于在教学和科研中查看医学影像（DICOM、NIfTI 和常见图片格式），不能用于诊断。

## 概要
**本程序不收集、不存储、不发送、不分享任何个人数据**，完全离线运行。

## 详细说明
- **不联网。** 程序不连接互联网或任何服务器，不含统计分析、广告、跟踪或崩溃上报功能。
- **影像只留在本机。** 只打开你选择的文件；导出的图片、DICOM / NIfTI 文件和视频只写入你选择的文件夹。
- **只有本机设置。** 程序在你的电脑上保存少量设置（如界面语言、是否已确认使用须知），位置是 `%LocalAppData%\ElephantDicomViewer`。其中不含影像数据和病人信息，也不会离开你的电脑。
- **临时文件。** 从 zip 压缩包解压的文件暂存在本机，关闭后删除。
- **多个窗口。** 同时打开几个程序窗口时，窗口之间只在本机内共享十字线位置。
- **病人信息。** DICOM 文件中可能含有病人信息，只显示在你的屏幕上。录制视频时可选择隐藏病人信息，导出时可选择匿名化。请按照你所适用的规定处理病人数据。

## 微软商城
如果你从微软商城安装本程序，微软可能按其自身的隐私声明收集下载和安装信息。本程序的开发者不会因此获得任何个人数据。
